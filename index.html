Participant Information & Informed Consent

Study Title: Digital Consumer Decision-Making in Travel & Ticketing

Conducted by: Master of Science in Economics, Gokhale Institute of Politics and Economics, Pune

Thank you for participating in this academic study. We are investigating consumer preferences, transaction habits, and decision-making during online ticketing and digital payment checkouts.

  • Procedure & Duration: You will be asked a few demographic questions, presented with a short hypothetical booking scenario, and asked to share your perceptions. The survey takes approximately 3–4 minutes.
  • Voluntary Participation: Your participation is entirely voluntary. You may choose not to answer specific questions or exit the survey at any time.
  • Anonymity & Privacy: Your responses are kept confidential. No identifying information is collected other than the traveller name you enter during the mock booking, which is used solely to classify and organize responses for analysis. No emails, phone numbers, or IP addresses are collected. Data will be analyzed strictly in aggregate form for academic coursework.
  • Eligibility: You must be 18 years of age or older to participate.

If you have any questions regarding this research, you may contact the research team at: sudeep.pg26219@gipe.ac.in

Consent Confirmation: By selecting "I Agree" below, you confirm that you are at least 18 years old, have read the information above, and voluntarily consent to participate in this study.

⚙ Researcher setup — Google Sheets integration

Send simulation data to a Google Sheet

"My sheet only gets responses from my own laptop"? That means the URL was only ever saved via the box below, which stores it in that one browser's local storage — it never reaches anyone else's device. To make it work for every participant, you must paste the URL into the SHEET_WEBAPP_URL constant near the top of the <script> in the HTML file itself (see step 7 below), then commit and push that change to GitHub so the published page already contains it for every visitor. The box below is only useful for testing on your own machine before you publish.

Paste your deployed Apps Script Web App URL below to test locally. Once saved, every completed "Make Payment" click in this browser will also send that session's data to your sheet (in addition to the local browser log). Leave this blank to keep logging locally only.

View Apps Script code & setup steps
  1. Open or create the Google Sheet you want this data logged to.
  2. Go to Extensions → Apps Script.
  3. Delete any starter code in the editor and paste in the script below.
  4. Click Deploy → New deployment, choose type Web app.
  5. Set "Execute as" to Me and "Who has access" to Anyone, then click Deploy and authorize the permissions Google asks for.
  6. Copy the Web App URL it gives you (it ends in /exec).
  7. Required for real participants: open the HTML file's source code, find the line const SHEET_WEBAPP_URL = ""; near the top of the <script> tag, paste your URL between the quotes, save the file, and push/commit it to the GitHub repo you're hosting from. Every visitor to the published page will now automatically log to your sheet — no per-browser setup needed.
  8. A "Responses" tab will be created automatically in your sheet the first time data arrives.

Already deployed an earlier version of this script? The code below now includes a "Traveller Name(s)" column, pulled from the First/Last Name fields travellers fill in during the Traveller Details step (multiple travellers are joined with a semicolon). Paste the updated code over your existing script in the Apps Script editor, save it, then go to Deploy → Manage deployments, click the pencil (edit) icon on your existing deployment, set Version to New version, and click Deploy. This pushes the updated code live on the same Web App URL — you don't need to reconnect the page. If your "Responses" tab already exists with older headers, either delete that tab (a fresh one with the new headers will be created automatically on the next submission) or manually update row 1 yourself.
